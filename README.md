# 兵峰射击游戏 (Bingfeng Shooter)

一个使用 HTML5 Canvas 开发的简单 2D 射击游戏。

## 游戏玩法

- **移动**：WASD 或方向键控制士兵移动
- **瞄准与射击**：移动鼠标瞄准，点击鼠标左键射击
- **目标**：消灭不断出现的敌人，累积分数
- **注意**：避免被敌人接近造成伤害，生命值归零游戏结束

## 在线游玩

1. 访问仓库：https://github.com/zhougeek-bot/bingfeng-shooter
2. 进入 **Settings** > **Pages**
3. 在 "Build and deployment" > "Source" 选择 **Deploy from a branch**
4. Branch 选择 **main**，Folder 选择 **/ (root)**
5. 点击 Save

几分钟后，游戏即可通过以下地址在线游玩：

**https://zhougeek-bot.github.io/bingfeng-shooter/**

## 本地运行

克隆仓库后，直接用浏览器打开 `index.html` 即可开始游戏。

## 技术说明

- 纯前端实现，无需后端
- 使用 Canvas 2D 绘制
- 支持键盘和鼠标控制
- 包含粒子爆炸效果和简单音效
